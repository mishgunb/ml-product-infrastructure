# GitHub и защита main

Репозиторий: https://github.com/mishgunb/ml-product-infrastructure

23 октября 2026 года для ветки `main` включена защита:

- изменения принимаются только через pull request;
- перед слиянием обязательна успешная проверка `quality` от GitHub Actions;
- ветка PR должна быть актуальна относительно main;
- обсуждения должны быть разрешены;
- правила действуют и для администратора, обход защиты запрещён;
- force push и удаление main запрещены.

Одобрение второго участника не требуется для личного учебного репозитория.
Линейная история не навязывается: для задания нужны merge-коммиты.

Защита включена после учебных слияний и разрешения конфликта, на коммите `309e857`.
С этого момента прямые коммиты и push в main не используются.
Изменения этой документации подготовлены в ветке `docs/submission` и переданы через PR.

## Следующие изменения

```sh
git switch main
git pull --ff-only
git switch -c feature/my-change
# Внести изменения.
make check
git add .
git commit -m "feat: describe the change"
git push -u origin feature/my-change
```

Затем открыть pull request в main, дождаться `quality` и выполнить слияние через GitHub.
Не отключать защиту для следующих лабораторных: они продолжают этот же репозиторий.

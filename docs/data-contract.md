# Контракт демонстрационных данных

Функция accuracy принимает два непустых списка целочисленных меток одинаковой длины.
Возвращает число от 0 до 1: долю совпавших меток. Пустые списки и несовпадающие длины
приводят к ValueError. Данные для демонстрации заданы в коде; внешние файлы не нужны.

Реальные датасеты, модели, отчёты и секреты не коммитятся. Для них предусмотрены
исключения в .gitignore. Lock-файл окружения, наоборот, хранится в Git.

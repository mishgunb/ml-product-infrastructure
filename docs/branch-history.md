## Ветки A и Б

Обе ветки созданы от `8ca754a`:

```sh
git switch -c A
# Изменение docs/team-agreement.md, коммит c29728c.
git switch main
git switch -c B
# Добавление docs/data-contract.md, коммит d7b9730.
git switch main
git merge --ff-only A
git merge --no-ff B -m "merge: integrate B with explicit --no-ff"
```

Слияние A передвинуло указатель main с `8ca754a` на `c29728c` без создания нового коммита.
Ветка A сохранена на GitHub, поэтому её вершину можно сравнить с историей main.
Слияние Б создало `7e4b611` с двумя родителями: `c29728c` и `d7b9730`.

## Конфликт и разрешение

От `7e4b611` создана ветка `conflict-demo`.
В ней коммит `979c4d3` заменил строку соглашения на
«Проверки выполняются перед каждым коммитом».
В main коммит `0c34457` заменил ту же строку на
«Проверки выполняются в CI каждого pull request».

Команда `git merge --no-ff conflict-demo` завершилась ошибкой
`CONFLICT (content): Merge conflict in docs/team-agreement.md`.
Конфликт разрешён вручную: сохранены оба требования в одной строке —
«Проверки выполняются перед каждым коммитом и в CI каждого pull request».

Коммит разрешения `309e857` имеет двух родителей: `0c34457` и `979c4d3`.
В сообщении коммита описан конфликт. Ветка `conflict-demo` сохранена на GitHub.

# Проверка локальной части

Проверено на macOS:

- В отдельной чистой папке без uv в PATH: `make setup`, `make check`, `make demo`
  успешно выполнены; uv загрузился автоматически.
- `make setup`: окружение Python 3.12.8 установлено, pre-commit подключён.
- `make check`: Ruff, проверка форматирования и строгий mypy проходят.
- `make hooks`: все три хука проходят.
- `make demo`: `Accuracy: 75.00%`.
- Замена аргумента `evaluate` с `list[int]` на `list[str]` приводит к ошибкам mypy:
  `make check` завершается ненулевым кодом, pre-commit hook блокирует коммит.
- Неиспользуемый `import os` приводит к F401: `make check` и hook завершаются ошибкой.
- Проверки не изменяют содержимое файлов. После негативных проверок исходный код восстановлен.

Внешняя часть (публикация, защита main и влитый PR) требует доступа к GitHub.
Эти проверки не подтверждают выполнение внешней части задания.
